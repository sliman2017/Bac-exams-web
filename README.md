# موقع تطبيق "جميع مواضيع البكالوريا مع الحل"

موقع ثابت (Static) جاهز للنشر مباشرة على GitHub Pages، يحتوي على:

- `index.html` — صفحة الهبوط الرئيسية (لقطات الشاشة مضمّنة داخله مباشرة بصيغة Base64، لا حاجة لأي ملف صور خارجي)
- `terms.html` — شروط الاستخدام
- `privacy.html` — سياسة الخصوصية
- `contact.html` — تواصل معنا
- `style.css` — التنسيق المشترك لكل الصفحات
- `screenshots/` — نسخة احتياطية من لقطات الشاشة الأصلية (اختيارية، غير مستخدمة في الموقع حاليًا)

## خطوات النشر على GitHub Pages

1. أنشئ مستودع (repository) جديد على GitHub، مثلاً باسم `bac-dz-app`.
2. ارفع الملفات الأربعة `.html` وملف `style.css` إلى جذر المستودع. لقطات الشاشة أصبحت مضمّنة مباشرة داخل `index.html` (Base64)، لذلك مجلد `screenshots/` غير ضروري لعمل الموقع — يمكن تجاهله أو رفعه كأرشيف فقط.
3. اذهب إلى **Settings → Pages** داخل المستودع.
4. تحت **Source**، اختر **Deploy from a branch**، ثم اختر الفرع `main` والمجلد `/ (root)`.
5. احفظ، وانتظر بضع دقائق. سيظهر رابط الموقع بالشكل:
   `https://username.github.io/bac-dz-app/`

## أشياء يجب تعديلها قبل النشر

ابحث عن هذه العناصر واستبدلها ببياناتك الحقيقية:

- **رابط Google Play**: كل زر "حمّل من Google Play" يحتوي `href="#"` — استبدله برابط صفحة تطبيقك على المتجر (في `index.html`).
- **البريد الإلكتروني**: `contact@example-bacapp.dz` في `contact.html` — استبدله ببريدك الفعلي (يظهر في مكانين: رابط mailto وحقل action في النموذج).
- **روابط فيسبوك وإنستغرام**: `href="#"` في `contact.html` تحت "معلومات التواصل".
- **اسم النطاق/الروابط الاجتماعية** إن وُجدت.

## ملاحظة حول نموذج التواصل

GitHub Pages لا يدعم معالجة النماذج من جهة الخادم (لا يوجد backend). النموذج الحالي يستعمل
`mailto:` فيفتح تطبيق البريد لدى الزائر مباشرة. إذا أردت استقبال الرسائل في لوحة تحكم بدل ذلك،
يمكنك ربط النموذج بخدمة مجانية مثل:

- [Formspree](https://formspree.io)
- [Web3Forms](https://web3forms.com)

فقط استبدل قيمة `action` في وسم `<form>` داخل `contact.html` برابط الخدمة التي تختارها.

## الخط والألوان

- الخط العناوين: Markazi Text (Google Fonts)
- خط النص: Tajawal (Google Fonts)
- الألوان الأساسية: أخضر داكن `#1F5C3E`، ذهبي `#C9962D`، خلفية ورقية فاتحة `#F5F6F1`

يمكنك تعديل هذه القيم من أعلى ملف `style.css` داخل `:root { ... }`.
