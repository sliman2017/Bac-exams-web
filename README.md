# موقع تطبيق "جميع مواضيع البكالوريا مع الحل"

## الملفات

- `index.html` — صفحة الهبوط الرئيسية
- `terms.html` — شروط الاستخدام
- `privacy.html` — سياسة الخصوصية
- `contact.html` — تواصل معنا
- `style.css` — التنسيق المشترك
- `favicon.svg` — أيقونة الموقع
- `robots.txt` — يخبر محركات البحث بما يمكنها فهرسته
- `sitemap.xml` — خريطة الموقع لتسريع الفهرسة
- `screenshots/` — لقطات شاشة التطبيق (ملفات حقيقية، **يجب رفعها مع الموقع**)

⚠️ **مهم:** لقطات الشاشة الآن ملفات منفصلة (وليست مضمّنة داخل الصفحة) لأن ذلك أخف بكثير وأفضل للسرعة
ولفهرسة الصور في Google Images. تأكد من رفع مجلد `screenshots/` بالكامل بنفس الاسم والمسار،
وإلا لن تظهر الصور (نفس المشكلة التي واجهتها سابقًا، سببها عدم رفع المجلد وليس خطأ في الكود).

## خطوة أولى إلزامية: استبدال رابط النطاق الوهمي

في كل الملفات التالية، استبدل **`https://your-sliman2017.github.io/bac-exams-web/`**
برابط موقعك الحقيقي بعد النشر (أو نطاقك الخاص إن ربطت دومين):

- `index.html` (canonical, Open Graph, Twitter Card, JSON-LD — عدة مواضع)
- `terms.html`, `privacy.html`, `contact.html` (canonical, Open Graph)
- `sitemap.xml` (كل الروابط)
- `robots.txt` (سطر Sitemap)

أسهل طريقة: افتح كل ملف وابحث عن `your-username.github.io/bac-dz-app` (Ctrl+H) واستبدلها دفعة واحدة.

كذلك استبدل في `index.html` داخل بيانات JSON-LD:
- `REPLACE_WITH_GOOGLE_PLAY_LINK` → رابط تطبيقك الحقيقي على Google Play

## خطوات النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا (مثلاً `bac-dz-app`).
2. ارفع **كل الملفات** بما فيها مجلد `screenshots/` إلى جذر المستودع مباشرة.
3. Settings → Pages → Deploy from a branch → `main` / `root`.
4. الرابط سيصبح `https://username.github.io/bac-dz-app/`.

## ما فعلته من جهة SEO التقنية (موجود بالفعل في الملفات)

| العنصر | أين | الفائدة |
|---|---|---|
| Title و meta description مخصصان لكل صفحة | كل الصفحات | يظهران في نتيجة البحث نفسها |
| `rel="canonical"` | كل الصفحات | يمنع مشاكل المحتوى المكرر |
| `meta robots: index, follow` | كل الصفحات | يسمح صراحة بالفهرسة والزحف |
| Open Graph + Twitter Card | كل الصفحات | معاينة جذابة عند مشاركة الرابط في فيسبوك/واتساب/تويتر |
| JSON-LD: `MobileApplication` | index.html | يساعد جوجل على فهم أن هذا تطبيق موبايل (قد يظهر بشكل مميز في النتائج) |
| JSON-LD: `FAQPage` + قسم أسئلة شائعة ظاهر فعليًا | index.html | فرصة لظهور "Rich Result" في جوجل ويستهدف عمليات بحث طويلة مثل "هل يوجد تطبيق مواضيع بكالوريا مجاني" |
| `sitemap.xml` + `robots.txt` | جذر الموقع | يسرّع اكتشاف جوجل لكل صفحاتك |
| صور بملفات حقيقية (لا Base64) + `width/height/loading` | index.html | صفحة أخف ~40× (من 1 ميغابايت إلى ~23 كيلوبايت)، سرعة تحميل أفضل = ترتيب أفضل، وقابلية فهرسة في Google Images |
| `fetchpriority="high"` على صورة البطل | index.html | يحسّن مؤشر LCP (أهم مؤشر سرعة تراقبه جوجل) |
| نص alt وصفي لكل صورة | كل الصور | إمكانية وصول أفضل + فهرسة صور أدق |
| هيكل عناوين صحيح (H1 واحد فقط لكل صفحة، ثم H2) | كل الصفحات | يساعد جوجل على فهم بنية المحتوى |
| favicon | كل الصفحات | إشارة ثقة بسيطة، يظهر في تبويب المتصفح ونتائج البحث على الموبايل |

## ما يجب أن تفعله أنت الآن (لا يمكن فعله من الكود وحده)

### 1. Google Search Console (الأهم على الإطلاق)
- سجّل دخول على https://search.google.com/search-console
- أضف موقعك (Domain أو URL prefix)
- تحقق من الملكية (عبر ملف HTML أو DNS)
- أرسل `sitemap.xml` من قسم "Sitemaps"
- اطلب فهرسة الصفحة الرئيسية يدويًا من "URL Inspection" لتسريع الظهور

### 2. Bing Webmaster Tools
نفس الخطوات على https://www.bing.com/webmasters — تحصل به على ترافيك إضافي مجاني بسهولة.

### 3. اختبارات تقنية سريعة
- **PageSpeed Insights**: https://pagespeed.web.dev — اختبر موقعك بعد النشر، هدفك فوق 90 على الموبايل
- **Mobile-Friendly Test**: تأكد أن جوجل يعتبر موقعك متوافقًا مع الموبايل (أغلب بحث الطلبة من الهاتف)
- **Rich Results Test**: https://search.google.com/test/rich-results — الصق رابط موقعك وتحقق أن JSON-LD يعمل بدون أخطاء

### 4. الروابط الخلفية (Backlinks) — أهم عامل ترتيب خارجي
محتوى ممتاز بدون روابط خارجية لن يتصدر أبدًا. جوجل يقيس "ثقة" موقعك بعدد ونوعية المواقع التي تشير إليه:
- شارك الموقع في مجموعات فيسبوك جزائرية لطلبة البكالوريا
- تواصل مع منتديات ومواقع تعليمية جزائرية لإضافة رابط موقعك في قوائم "أفضل تطبيقات البكالوريا"
- إن كان لديك حساب فيسبوك/إنستغرام للتطبيق، ضع رابط الموقع في البايو وفي كل منشور
- سجّل الموقع في أدلة تطبيقات عربية (App Directories)

### 5. المحتوى — جوجل يفضل المواقع النشطة
- فكّر بإضافة صفحة/مدونة بسيطة بعنوان مثل "نصائح للنجاح في البكالوريا 2026" أو "كيف تراجع بفعالية لكل مادة" — محتوى نصي طويل نسبيًا (800+ كلمة) يستهدف كلمات مثل "طريقة المراجعة للبكالوريا" يجلب زيارات لا علاقة لها مباشرة بالتطبيق لكنها تبني سلطة الموقع (Domain Authority)
- حدّث الصفحة الرئيسية عند كل دورة بكالوريا جديدة (يشير لجوجل أن الموقع "حي")

### 6. الكلمات المفتاحية التي يجب استهدافها بمرور الوقت
بالعربية والفرنسية معًا لأن جزءًا كبيرًا من الجزائريين يبحث بالفرنسية:
`مواضيع البكالوريا`, `bac dz`, `sujets bac algerie`, `تحضير بكالوريا 2026`, `corrigés bac algérie`, `تطبيق بكالوريا الجزائر`

### 7. الاسم التجاري والاتساق (E-E-A-T)
جوجل يعطي ثقة أكبر للمواقع ذات هوية واضحة:
- استعمل نفس الاسم بالضبط (جميع مواضيع البكالوريا مع الحل) في: الموقع، صفحة Google Play، حسابات التواصل الاجتماعي
- أضف بريدًا إلكترونيًا حقيقيًا (ليس placeholder) في `contact.html`
- إن أمكن، أضف اسم فريق العمل أو "من نحن" — الشفافية تعزز الثقة

### 8. الأداء بعد النشر
- راقب Google Search Console أسبوعيًا في الشهر الأول (تظهر أخطاء الزحف والفهرسة هناك)
- لا تُغيّر روابط الصفحات (URLs) بعد نشرها؛ لو احتجت لذلك مستقبلاً استعمل إعادة توجيه 301

## ترتيب الأولوية الواقعي

الترتيب الأول في جوجل على كلمات تنافسية مثل "بكالوريا الجزائر" يستغرق عادة **أشهرًا** ويعتمد
بشكل كبير على الروابط الخلفية والنشاط المستمر، وليس فقط على تحسينات الكود. الكود الآن جاهز
تقنيًا 100%؛ الخطوة الحاسمة التالية من جهتك هي **Google Search Console + الروابط الخلفية**.
